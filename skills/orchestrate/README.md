# Orchestrate

Routes one task to a runtime and checks that old routes stay retired.

| File | Purpose |
|---|---|
| `README.md` | Explains this skill's files. |
| `SKILL.md` | Gives agents the routing rules and commands. |
| `bin/` | Holds the routing and brief check commands. |
| `replays/` | Holds fixed briefs and routes for replay checks. |
| `tests/` | Holds resolver, doctor, and brief check tests. |
