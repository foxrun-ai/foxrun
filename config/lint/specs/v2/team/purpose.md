# Purpose: the team page

| Reader | Comes with the question | Leaves for |
|---|---|---|
| Person, the operator; not an engineer | Who works in this workspace, and who leads it? | The seat file of the one he wants, by its name in the table |
| An agent at the start of a session | Who is the lead, and which seat can take this work, on which runtime? | The lead's seat file; then `AGENTS.md` for the rule on leads |
| A new person who installed Foxrun | What is a seat, and where are its files? | The `Files` tree; then the shared seats in the system home |

**In ten seconds the page must answer:** who the lead is, and what each seat does.

**Moving on:** the `Go to` line opens the state page, the capabilities page, and the index. Each seat name opens its file.

## The check against version 1

| The page must | Version 1 | Version 2 |
|---|---|---|
| Name the lead first | Yes: the first line | The same |
| Say what each seat does, in the seat's own words | Yes: the seat's summary, whole | The same |
| Show the way to the next page | Only to seat files and `AGENTS.md` | A `Go to` line: state, capabilities, index |
| Say what each file in the folder is | Yes: the `Files` tree | The same |
| Keep a person's notes across builds | Yes: `Notes` | The same |
