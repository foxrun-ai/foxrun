# Purpose: the three view pages

The view is in the system home. A person looks there; a person edits in the workspace.

| Page | Reader | Comes with the question | Leaves for |
|---|---|---|---|
| `TEAM.md` | Person, the operator | Who works in this workspace, and who leads? | The seat file, by its name in a row |
| `SKILLS.md` | Person; an agent that plans a task | What can this workspace do, by use? | The skill, or the tool it needs |
| `TOOLS.md` | Person; a new person | Which tools does this workspace have, and what is each one for? | The tool page, by its name in a row |

**In ten seconds each page must answer:** how many there are, and what each one does, without a visit to the workspace.

**Moving on:** the nav line joins the three pages. The source line opens the folder in the workspace.

## The check against version 1

| The page must | Version 1 | Version 2 |
|---|---|---|
| Answer by use, not by letter | One flat table, A to Z | A topic for each use; the skills or tools under it |
| Say how a tool helps | The first sentence of the page, in any register | The first sentence of the plain summary of the tool page |
| Say what `Needs` lists | A bare id: `datadoe` | `Tools it needs`: plain name, link, and a few words |
| Show the gaps | Yes | Yes; a tool page not on the template is under `No use yet` |
