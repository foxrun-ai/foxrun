# Purpose: the tool page

| Reader | Comes with the question | Leaves for |
|---|---|---|
| Person, the operator; not an engineer | What is this thing, and how do I use it today? | The capabilities page, by the link in the `Use` row |
| An agent at the start of a task | Can I use this tool now, how do I call it, and what needs his yes? | The skill that needs it, by a link in `Skills that need it` |
| A new person who installed Foxrun | How do I install it, and how do I know it works? | The install page, by the link in the `Install` line |

**In ten seconds the page must answer:** what the tool is, in its makers' words and in plain words, and how he uses it.

## The check against version 2

| The page must | Version 2 | Version 3 |
|---|---|---|
| Say what the tool is | It described his wrapper: sessions he lists and closes by number | The makers' words from the tool's own README or help, then one plain sentence |
| Keep his use apart from the tool | Mixed in the summary and in `Use` | "How Person uses it", labeled; `Use` holds only the tool's own commands |
| Show the source | Only in `proof.tsv` | A `Source` row on the page, and `proof.tsv` |
| Hold for every later writer | A rule for form only | A writer note in the template and four content rules in the spec |
