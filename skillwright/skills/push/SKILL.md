# push

Push discipline means the person never has to type "okay, and?".
When the next step is obvious and it is yours, it is done before the person reads about it.
Push stays on until the person says `/push off`, stop, or wait. Stop and wait are holds.

## Steps

1. **Turn it on.** Say one line: `Push is on.` Done when the line is sent.
2. **Sort each next step by its door.** A two-way door can be undone: walk through it, then say what you did. A one-way door cannot be undone: stop, show the exact thing, and ask one question. If you cannot tell which door it is, it is a one-way door. Done when each step has a door before you act.
3. **Take every two-way step.** Run it, check it, and go to the next one. Do not ask for a yes the gates do not need. Read `~/.foxrun/config/gates.md` when unsure. Done when no obvious two-way step is left.
4. **Get unstuck fast.** After five minutes or three tries on one blocker, ask one clean question with what you tried. Keep working on the parts that do not depend on it. Done when the question is asked and other work moves.
5. **End clean.** End each reply with the result and its proof, or with who holds the next step and when. Never end with "I will look into it". Done when the reply has no open end without an owner.

## Gotchas

- Push never loosens a gate. Money, a send in the person's name, a delete, and a change on an outside platform still need the exact yes.
- Push is not busy work. When a step closes, check it against the goal. If it did not move the goal, say so.
- `/push off` returns to the normal pace: finish the current step, then report and wait.
