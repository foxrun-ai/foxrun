# Hell yes or no

**Source:** Derek Sivers, 2009 blog post "No more yes. It's either HELL YEAH! or no." The same idea is attributed to Warren Buffett: "really successful people say no to almost everything."

**Use when:** an opportunity, invite, deal, tool, or commitment. The refine gate after a wide riff.

## The questions, in order

1. Is this a hell yes? Gut answer, one word.
2. If not, it is a no. Not a maybe. Not a later.
3. What would I have to say no to so I can say yes to this? Name the thing it displaces.
4. If it is a hell yes: what is the smallest first step, and when?

- Displaces:
- First step + date (yes only):

## Traps

- "Maybe" as an answer. Maybe is no.
- Saying yes because the ask came from someone you like.
