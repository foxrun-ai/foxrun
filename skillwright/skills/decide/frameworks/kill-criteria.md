# Kill criteria

**Source:** Annie Duke, "Quit: The Power of Knowing When to Walk Away" (2022) and "Thinking in Bets" (2018). Former professional poker player, World Series of Poker bracelet 2004.

**Use when:** something is about to start running, or is already running: an overnight run, an experiment, a tool eval, a campaign, a project. Set the stop rule before the sunk cost exists.

## The questions, in order

1. What signal would tell us this is not working? Name the signal, the number, and the date. "If by <date> we do not see <signal>, we stop."
2. Who calls it? One name.
3. What do we do the moment it fires? Stop, archive, and write the one-line lesson.
4. Already running with no kill criteria? Write them now. Then ask: knowing what we know today, would we start this? If not, stop.
5. Judge the decision by the process at the time, not the result. Good decision, bad outcome happens.

## Output

- Kill criteria: signal + number + date
- Owner:
- On fire: stop / archive / lesson
- Start it? yes / no

## Traps

- Criteria with no date. They never fire.
- Moving the goalposts when the signal fires.
